Pivot tables and Excel export for TanStack tables.

Rowpine adds the two things TanStack Table leaves to you: pivoting and a proper Excel and PDF export. It works from the table instance you already have, so your columns, filters and shadcn/ui styling stay as they are.

In development. No package is published yet.

Pivot tables

TanStack Table can group rows, but it has no pivot. Rowpine turns your rows into a pivot with fields on both axes and gives the result back as rows and columns that your existing table renders.

  • Several fields on each axis, nested

  • Groups that expand and collapse
  • Custom sort for each axis

Excel and PDF export

The export writes the table the way your users see it, from the same table instance. You don't write a column mapping.

Groups become outline rows you can collapse in Excel. Dates and amounts are typed cells, so they sort and sum.
  • Column order and widths
  • Hidden columns stay out
  • Pinned columns become frozen panes
  • Only the rows that pass the current filter
  • The current sort
  • Groups as Excel outline rows
  • Aggregates as formulas, not pasted numbers
  • Numbers and dates as typed cells with their format
  • Cell colors from conditional formatting
  • Selected rows only, when you ask for it

How it will install

The pivot panel and the export menu come from the shadcn registry, so their source lands in your project and uses your theme. The pivot engine and the file writers are an npm package.

npx shadcn add @rowpine/pivot @rowpine/export
const pivot = usePivot(rows, {
  rows: ['region'],
  cols: ['quarter'],
  values: [{ field: 'amount', agg: 'sum' }],
})

<ExportMenu table={table} fileName="orders" />

Planned API. Names may change before the first release.

Pricing

CSV export is free. Pivoting and Excel and PDF export come in one Pro license: a one-time payment per developer that includes a year of updates. You keep every version released during that year, including new Pro features. Prices will be posted at launch.
