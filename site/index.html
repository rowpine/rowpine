How it works

Three steps on the table you already have

  1. Install the packageThe file writers and the pivot engine, typed, with three runtime dependencies.npm install rowpine
  2. Add the componentsThe export menu and the pivot designer arrive as source in your project, styled by your shadcn theme.npx shadcn add https://rowpine.com/r/export-menu.json
  3. Pass your tableNo column definitions to repeat. Or call the export functions from your own buttons.<ExportMenu table={table} />
Installation guide
orders-table.tsxmain.tsx
import { ExportMenu } from "@/components/export-menu"
import { exportXlsx, exportPdf } from "rowpine"

export function OrdersTable() {
  const table = useTable({ features, columns, data })

  return (
    <div>
      <ExportMenu table={table} fileName="orders" />
      {/* your shadcn <Table> */}
    </div>
  )
}

// or from your own button
await exportXlsx(table, { fileName: "orders" })
await exportPdf(table, { title: "Orders", pageSize: "A4" })

FAQ

Questions teams ask before they buy

Something else? Write to info@jqwidgets.com and an engineer answers.

Do we have to replace our table?

No. Rowpine reads the TanStack table instance you already render. Your columns, cells and shadcn/ui styling stay as they are.

Does any of our data leave the browser?

No. Excel and PDF files are built on the user's machine, and the license key is checked there too. The package makes no network calls.

What happens without a license key?

Everything runs. Excel and PDF files carry one notice line, and the console shows a message once. Nothing is switched off, so a missing key never breaks production.

What happens after the year of updates?

Your key covers every version released during that year, for good. Renew only when you want the next year of versions.

Who needs a license?

Each developer who writes code that uses the Pro features. The people who use your app do not, and there is no limit on apps, users or servers.

Can we change the components?

Yes. The export menu, pivot table and pivot designer install as MIT source in your repository. The file writers and the pivot engine are the rowpine npm package.
