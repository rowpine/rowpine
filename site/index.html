Export the table you see to Excel and PDF.

Rowpine takes a TanStack Table or shadcn/ui data table and writes a real .xlsx or PDF from it, with the groups, filters, column order and number formats your users are looking at. You don't write a column mapping.

In development. No package is published yet.

Groups become outline rows you can collapse in Excel. Dates and amounts are typed cells, so they sort and sum.

What the export keeps

  • Column order and widths
  • Hidden columns stay out
  • Pinned columns become frozen panes
  • Only the rows that pass the current filter
  • The current sort
  • Groups as Excel outline rows
  • Aggregates as formulas, not pasted numbers
  • Numbers and dates as typed cells with their format
  • Cell colors from conditional formatting
  • Selected rows only, when you ask for it

How it will install

The export menu comes from the shadcn registry, so its source lands in your project and uses your theme. The file writers are an npm package.

npx shadcn add @rowpine/export
<ExportMenu table={table} fileName="orders" />

Planned API. Names may change before the first release.

Pricing

CSV export is free. Excel and PDF export are a one-time license per developer that includes a year of updates. You keep every version released during that year. Prices will be posted at launch.

Follow along

Watch rowpine/rowpine on GitHub to hear about the first release. Issues are open if you have a table that exports badly today and want it covered.

Rowpine. TanStack Table and shadcn/ui are separate projects and are not affiliated with Rowpine.
