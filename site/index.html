Excel, PDF and pivot tables for TanStack Table

Rowpine is an npm package. You give it your TanStack Table instance (v8 or v9) and it writes an Excel, PDF or CSV file of the table as the user has it on screen: their filters, sort order, grouped rows, hidden and pinned columns. It also has a pivot engine and a pivot designer for shadcn/ui.

CSV export is free. Excel, PDF and the pivot work without a license key too, and each file gets one notice line at the bottom. A license removes that line, paid once: $29 if you work on your own or your company earns under $1M a year, $149 per developer otherwise.

What the Excel file looks like

This is the file from the Excel guide. The table was grouped by region and then product, so those are Excel outline levels with the collapse buttons on the left. The group totals are formulas: E2 is =SUBTOTAL(9,E3:E14). They update when someone edits a number, and a region total does not count its product totals twice, which a SUM would. Amounts are numbers with a currency format, so they sort and add up in Excel.

You can open the real files. They were made without a license key, so the notice line is at the end: orders.xlsx, payments-report.pdf.

The code

import { exportXlsx, exportPdf } from "rowpine"

await exportXlsx(table, { fileName: "orders" })
await exportPdf(table, { fileName: "orders", title: "Orders" })

If you use the shadcn/ui data table, there is also an export menu: npx shadcn add @rowpine/export-menu. It lands in your project as MIT source, and it reads your theme colors so the PDF matches the app. Column formats, widths and colors go in meta.rowpine on your column definitions; see column settings.

Pivot tables

createPivot(rows, { rows, cols, values }) returns data and columns you pass to your own useTable, so the pivot is an ordinary TanStack table. Or add the PivotTable and PivotDesigner components, where users drag fields themselves. A pivot exports to Excel with the same outline levels and formulas. The pivot guide walks through both.

What it does not do

  • It does not read Excel files. It only writes them.
  • It works with TanStack Table only. If you use another table library, it will not help you.
  • It runs in the browser and is tested there, not on a server.
  • Excel files get no charts. A PDF can include chart images that you pass in.
