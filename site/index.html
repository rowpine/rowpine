Why Rowpine?

  • TanStack Table v8 and v9
  • shadcn/ui Base UI and Radix
  • Runs in the browser
  • One-time license

TanStack Table gives you a headless table and leaves the rest to you. Rowpine is the rest, for the two jobs users ask for most: pivoting and getting the data into Excel.

Your table stays yours

Rowpine reads the TanStack table you already render. No new grid to learn and no column definitions to repeat.

Files match the screen

Visible columns in screen order, the current filter and sort, groups in place, pinned columns frozen.

Real Excel files

Typed numbers and dates with their formats, outline rows, SUBTOTAL formulas and cell colors. Not a CSV renamed.

The pivot TanStack lacks

Fields on both axes, several measures, eight aggregations, subtotals and totals, and a designer.

Source in your project

The export menu and the pivot designer install from the shadcn registry as code you can read and change.

Nothing leaves the browser

Files are built on the user's machine. License keys are checked offline, with no call to a server.

Export

One line on the table you have

Pass your table to the export menu, or call the export functions from your own buttons. The file follows whatever the user set up on screen.

  • Every filtered row, on every page, in the current sort
  • Groups and tree rows as Excel outline levels
  • Pinned columns become frozen panes
  • Selected rows only, when asked
Add an export menu 
// npx shadcn add https://rowpine.com/r/export-menu.json
import { ExportMenu } from "@/components/export-menu"

const table = useTable({ features, columns, data })

<ExportMenu table={table} fileName="orders" />

// or from your own button
await exportXlsx(table, { fileName: "orders" })
await exportPdf(table, { title: "Orders" })
