Components

The shadcn registry items: an export menu, a pivot table and a pivot designer. Their source is in your project after npx shadcn add.

rowpine 1.0.3Generated from the package's type definitions

ExportMenu

component

A dropdown button that exports the table to Excel, PDF or CSV and saves the file. While an export runs the button reads "Exporting..." and further picks are ignored. A "Selected rows only" checkbox appears when the table has selected rows, or as allowSelectedOnly says.

Source in your project: components/export-menu.tsx

pdfOptionsoptionalPdfTableExportOptionsMore PDF options, such as pageSize or kpis. They win over the theme colors.
xlsxOptionsoptionalXlsxExportOptionsMore Excel options, such as sheetName. They win over the theme colors.

usePivot

Pivot data with config; recomputes only when either changes.

Parameters

NameTypeDescription
datareadonly TData[]Source rows. A new array on each render rebuilds the pivot.
configPivotConfig<TData>The pivot config. Keep the same object between renders (a constant or useMemo); a new one rebuilds the pivot.
optionsoptionalToColumnsOptionsSettings for every value column, such as an Excel number format. Same rule as config.
