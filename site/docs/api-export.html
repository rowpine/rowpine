Export functions

Write a TanStack table to Excel, PDF or CSV, the options each export takes, and the colors from your theme.

rowpine 1.0.3Generated from the package's type definitions

exportXlsx

function

Export the table to an .xlsx file. Returns the file as a Blob. Without a valid license key it still exports, adds the unlicensed notice line below the data, and logs a console warning once per page load.

Signature
exportXlsx(table: TableLike, opts?: XlsxExportOptions) => Promise<Blob>

Parameters

NameTypeDescription
tableTableLikeA TanStack table (v8 or v9), or pivot.table from createPivot.
optsoptionalXlsxExportOptionsExport options. Default: every row, saved as 'export.xlsx'.

Returns

Promise<Blob>

exportPdf

function

Export the table to a PDF file. Returns the file as a Blob. Loads pdfmake and its fonts on first use. Without a valid license key it still exports, prints the unlicensed notice line below the table, and logs a console warning once per page load.

Signature
exportPdf(table: TableLike, opts?: PdfTableExportOptions) => Promise<Blob>

Parameters

NameTypeDescription
tableTableLikeA TanStack table (v8 or v9), or pivot.table from createPivot.
optsoptionalPdfTableExportOptionsExport options. Default: every row on A4, saved as 'export.pdf'.

Returns

Promise<Blob>

exportCsv

function

Export the table to a CSV file. Returns the file as a Blob. Free: no license check.

exportCsv(table: TableLike, opts?: CsvExportOptions) => Promise<Blob>

Parameters

NameTypeDescription

Returns

tableToCsv

function

The table as CSV text: a header line, then one line per data row. Group rows are left out. Lines end with CRLF. No byte order mark and no file.

Signature
tableToCsv(table: TableLike, opts?: CsvExportOptions) => string

Parameters

NameTypeDescription
tableTableLikeA TanStack table (v8 or v9), or pivot.table from createPivot.
optsoptionalCsvExportOptionsWhich rows to write and the field separator. Default: every row, ','.

Returns

string

exportThemeFromPage

function

Read the shadcn/ui theme colors (--background, --foreground, --muted, --border) from the page and return them as export colors. Returns no colors outside a browser, when a variable is missing, or for a dark theme. ExportMenu does this for you; call it when you export from your own buttons.

Signature
exportThemeFromPage(element?: Element) => ExportTheme

Parameters

NameTypeDescription
elementoptionalElementWhere to read the variables. Default: the document's root element.

Returns
