Column settings

Per-column export settings, read from meta.rowpine on your TanStack column definitions.

rowpine 1.0.3Generated from the package's type definitions

RowpineColumnMeta<TData = any>

type

Per-column export settings, read from columnDef.meta.rowpine.

Properties

NameTypeDescription
headeroptionalstringHeader text in the file. Default: the column's string header, else its id.
numFmtoptionalstringExcel number format, e.g. '"$"#,##0.00' or 'yyyy-mm-dd'.
formatoptional((value: unknown, row: TData) => string)Display text for PDF. CSV writes the raw value. Default: numbers and dates in the browser locale.
widthoptionalnumberColumn width in px. Default: the column's TanStack size.
alignoptional"left" | "center" | "right"Horizontal alignment. Default: right for numbers, left otherwise.
cellStyleoptional((value: unknown, row: TData) => CellStyle | undefined)Cell colors, e.g. for conditional formatting.
excludeoptionalbooleanLeave this column out of every export. Default: true for display columns (no accessor, such as checkboxes and row actions), false otherwise.

CellStyle

type

Colors and weight for one cell or a whole row, in Excel and PDF exports. CSV ignores it.

Properties

NameTypeDescription
filloptionalstringBackground color, '#rrggbb'. The Excel writer ignores other forms.
coloroptionalstringText color, '#rrggbb'. The Excel writer ignores other forms.
boldoptionalbooleanBold text.
