Rowpine documentation

Excel, PDF and CSV export and pivot tables for TanStack Table and shadcn/ui. Install it, add a component, and pass it the table you already render.

rowpine 1.0.2TanStack Table 9.3.1 and 8.21.3React 19.3.1shadcn/ui Base UI and Radix

Quick start#

Terminal
npm install rowpine
npx shadcn add https://rowpine.com/r/export-menu.json
orders-table.tsx
import { ExportMenu } from "@/components/export-menu"

<ExportMenu table={table} fileName="orders" />

That gives your table an Excel, PDF and CSV menu. Installation covers the details, and license keys what changes when you buy.
