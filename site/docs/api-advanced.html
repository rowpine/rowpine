ColumnLike

interface

The parts of a TanStack column the exporters read.

Properties

NameTypeDescription
idstringTanStack column.id. Used as the column key when reading row values.
columnDef{ header?: unknown; meta?: unknown; aggregationFn?: unknown; accessorFn?: unknown; accessorKey?: unknown; }TanStack column.columnDef. The exporters read its string header, meta.rowpine, a string aggregationFn (for Excel SUBTOTAL formulas), and accessorFn / accessorKey to tell data columns from display columns.
accessorFnoptionalunknownTanStack sets this on columns with an accessor.

SheetColumn

type

One exported column of a Sheet, with its meta.rowpine settings resolved.

Properties

NameTypeDescription
idstringThe TanStack column id.
headerstringHeader text: meta.rowpine.header, else the string header, else the id, after any parent group headers joined with ' / '.
widthnumberWidth in px: meta.rowpine.width, else the column's TanStack size, else 150.
align"left" | "center" | "right"meta.rowpine.align. Undefined writes no alignment to Excel, and the PDF aligns numbers right.
numFmtoptionalstringmeta.rowpine.numFmt: the Excel number format.
formatoptional((value: unknown, row: unknown) => string)meta.rowpine.format: display text for the PDF.
cellStyleoptional((value: unknown, row: unknown) => CellStyle | undefined)meta.rowpine.cellStyle: colors for data cells.
subtotaloptional"auto" | SubtotalAggThe column's aggregation when it maps to SUBTOTAL; auto resolves per value.

XlsxModel

type

A single-sheet workbook as data: what buildXlsxParts writes.

Properties

NameTypeDescription
sheetNamestringWorksheet name. Characters Excel forbids in a sheet name become spaces, the name is cut to 31 characters, and an empty result becomes 'Sheet1'.
headerreadonly string[]Header labels (row 1).
rowsreadonly (readonly XlsxCell[])[]Data rows (each an array of cells, column-aligned with header).
widthsoptionalreadonly number[]Per-column widths in pixels (optional).
freezeHeaderoptionalbooleanFreeze the header row.
freezeColumnsoptionalnumberFreeze this many leading columns.
condFormatsoptionalreadonly XlsxCondFormat[]Native column conditional formatting (data bars / color scales).
tableoptionalXlsxTableSpecWrap the data in a native Excel Table.
outlineoptionalreadonly number[]Outline level per data row (0 = top level), aligned with rows. Rows with a level above 0 form groups Excel can collapse; the summary row sits above its detail rows, as on screen.
notesoptionalreadonly string[]Plain text lines written below the data, after one empty row.

XlsxCell

type

One worksheet cell, already resolved by the caller.

Properties

NameTypeDescription
t"n" | "d" | "s" | "b"'n' number, 'd' date, 's' string, 'b' boolean.
valuestring | number | boolean | Date | nullThe value. Without a formula, null, undefined and '' write an empty cell. A 'd' value that is not a Date is parsed; 'YYYY-MM-DD' is that local day.
formulaoptionalstringA formula without the leading '=', e.g. SUBTOTAL(9,C3:C9). value is written as its cached result, so viewers that do not recalculate still show the number.
numFmtoptionalstringExcel number-format code (for 'n' / 'd').
alignoptional"left" | "center" | "right"Horizontal alignment. 'left' writes no alignment, the same as leaving it out.
filloptionalstringBackground fill hex (e.g. '#fee2e2').
coloroptionalstringFont color hex.
boldoptionalbooleanBold text.
linkoptionalstringHyperlink URL.
