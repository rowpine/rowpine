PivotRow

type

Shape of one entry in result.rows. The first-column label lives at __pivotLabel; every value cell lives at the column id matching the leaf column generated for its (col-path × measure).

__pivotParentId is the __pivotId of the row's row-axis parent (or null for top-level groups, the grand-total row, and the one synthetic "All" row when no row dims are configured). Use it with filterCollapsedPivotRows to hide leaves whose ancestor is collapsed - that's how expandable pivots are built on top of the model.

__pivotExpandable is true for group rows that have at least one descendant. A renderer uses this to decide whether to show a chevron next to the label.

Properties

NameTypeDescription
__pivotIdstringUnique id built from the row's path of values. The grand-total row is 'row__grand_total'.
__pivotKindPivotRowKind'group' (holds the group's subtotals unless rowSubtotals is false), 'leaf' or 'grandTotal'.
__pivotDepthnumberLevel on the row axis: 1 under the first row field, 2 under the second, and so on. 0 on the grand-total row and on the single row of a pivot with no row fields.
__pivotLabelstringText of the first column: the row's value on the row axis, 'Grand total' on the grand-total row, '(All)' on the single row of a pivot with no row fields.
__pivotParentIdstring | null__pivotId of the group row this row sits under, or null at the top level.
__pivotExpandablebooleanTrue on group rows, which always have rows under them.

PivotRowKind

What a pivot row represents: a group row (which carries the group's subtotals), a leaf, or the grand total. The engine does not emit subtotal; it is kept in the type so existing code that checks for it still compiles.

filterCollapsedPivotRows

function

Filter a result.rows array down to only the rows the user should see given the current expansion state. A row stays in the output if its entire ancestor chain (via __pivotParentId) is in expandedIds.

Pass true to bypass filtering (everything visible - the default shape createPivotModel already returns). Pass an empty array / empty Set to collapse every group to its subtotal row.

The result is a new array; the input is not mutated.

Signature

  rows: ReadonlyArray<PivotRow>,
  expandedIds: ReadonlyArray<string> | Set<string> | true,
) => PivotRow[]

Parameters

NameTypeDescription
rowsreadonly PivotRow[]Rows as createPivotModel returns them.
expandedIdsanyIds of the expanded group rows, or true to keep every row.
