Pivot designer state

The fields, layouts and presets behind the pivot designer, and the pure functions that change a layout.

rowpine 1.0.3Generated from the package's type definitions

PivotField<T = Record<string, unknown>>

type

One field the designer offers. Dimensions land in Rows by default; measures in Values.

Properties

NameTypeDescription
fieldkeyof T & stringKey of the field in each data row.
labelstringName shown in the field list and on chips.
kind"dimension" | "measure"'dimension' may go to Rows, Columns or Filters; 'measure' to Values or Filters.
groupoptionalstringOptional group heading in the field list, e.g. 'Customer'.
formatoptional((value: unknown) => string)Display text for this field's values when it is a measure.
defaultAggoptionalPivotAggregatorIdAggregation used when the field is added to Values. Default 'sum' for measures.

PivotLayout

type

The whole designer state, as plain JSON.

Properties

NameTypeDescription
rowsstring[]Fields in the Rows well, outer-most first.
colsstring[]Fields in the Columns well, outer-most first.
valuesPivotValueChip[]Chips in the Values well, in column order.
filtersPivotFilterChip[]Chips in the Filters well.
hideSubtotalsoptionalbooleanShow no numbers on group rows. The group rows stay and still expand and collapse.
hideGrandTotalsoptionalbooleanHide the grand-total row and column.

addToWell

function

Add a field to a well at index (default: the end). In Rows, Columns and Filters a field appears at most once, so adding it moves it. In Values the same field may appear with different aggregations (sum and average of one amount), but not twice with the same one. sourceIndex is the chip's position in Values when it is being moved out of that well. Returns the layout unchanged when field is not in fields.

Signature
addToWell<T>(
  layout: PivotLayout,
  fields: ReadonlyArray<PivotField<T>>,
  field: string,
  well: Well,
  index?: number,
  sourceIndex?: number,
) => PivotLayout

Parameters

NameTypeDescription
layoutPivotLayoutThe current layout. Not changed.
fieldsreadonly PivotField<T>[]The fields the designer offers.
fieldstringKey of the field to add.
wellWellThe well to add it to.
indexoptionalnumberPosition in the well. Default: the end.
sourceIndexoptionalnumberWhen moving a chip out of Values, its position there. A chip moved within Values keeps its aggregation.

Returns

PivotLayout
